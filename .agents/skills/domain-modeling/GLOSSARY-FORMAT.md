# Vocabulary format for this repository

Maintain the existing term table in `docs/domain-model.md`. Use a canonical term and a concise definition per row. Clarify aliases when they cause ambiguity. Keep implementation mappings in the document's separate sections. Do not create `GLOSSARY.md`, `GLOSSARY-MAP.md` or `CONTEXT.md` for this single-context project.

Definitions describe the domain. New terms should be supported by code or a decision settled with the user. Preserve the distinction between a concrete scenario, a resilience configuration and an observed/replayed result.
